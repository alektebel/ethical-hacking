# Level 5: Advanced Topics

Explore specialized areas of ethical hacking including wireless security, cryptography, and web application security.

## Learning Objectives

- Understand wireless network security
- Master cryptographic concepts
- Learn web application vulnerabilities
- Study advanced attack vectors

## Projects

### Project 5.1: Wireless Network Analysis
Understand WiFi security and common attacks.

**Topics:**
- 802.11 protocol
- WPA/WPA2 security
- Deauthentication attacks
- Packet injection
- Wireless sniffing

### Project 5.2: Cryptography & Hash Cracking
Learn cryptographic principles and weaknesses.

**Topics:**
- Symmetric vs asymmetric encryption
- Hash functions
- Rainbow tables
- Password cracking
- Cryptographic attacks

### Project 5.3: Web Application Security Basics
Understand common web vulnerabilities.

**Topics:**
- SQL injection
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Authentication bypass
- Session hijacking

## Prerequisites

- Completed Levels 0-4
- Programming in multiple languages
- Understanding of cryptography basics
- Web development knowledge (for 5.3)

## Important Notes

⚠️ **Wireless Security**
- Only test networks you own
- Jamming/deauth can be illegal
- Check local regulations

⚠️ **Password Cracking**
- Only crack your own passwords/hashes
- Do not use stolen databases
- Understand legal implications

⚠️ **Web Security**
- Test only with permission
- Use intentionally vulnerable apps (DVWA, WebGoat)
- Never attack production websites
