# Level 0: Fundamentals

Welcome to Level 0! This is where your ethical hacking journey begins. Before diving into network security and exploitation, you need to master the fundamentals.

## Why These Fundamentals Matter

- **C Programming**: Most security tools and exploits are written in C. Understanding memory management, pointers, and low-level operations is crucial.
- **Networking**: You can't hack what you don't understand. Deep knowledge of how networks work is essential.
- **Assembly**: Understanding what happens at the CPU level helps you write exploits and analyze malware.

## Projects in This Level

### Project 0.1: C Programming Basics & Memory Management
Learn C programming with a security mindset. Understand pointers, memory allocation, and common pitfalls.

**Topics Covered:**
- Pointers and memory addresses
- Dynamic memory allocation
- Buffer handling
- Common vulnerabilities in C code

### Project 0.2: Networking Fundamentals & Socket Programming
Build your first network programs using sockets. Understand how applications communicate.

**Topics Covered:**
- TCP/IP basics
- Client-server architecture
- Socket programming in C
- Network byte order

### Project 0.3: Introduction to Assembly Language
Learn to read and write assembly code. Essential for understanding exploits and reverse engineering.

**Topics Covered:**
- CPU registers and instructions
- Stack operations
- Calling conventions
- Basic shellcode concepts

## How to Progress

1. Complete each project in order
2. Do all the exercises - they build on each other
3. Experiment and break things (in your safe environment!)
4. Move to Level 1 only when you're comfortable with these concepts

## Estimated Time

- Project 0.1: 1-2 weeks
- Project 0.2: 1-2 weeks
- Project 0.3: 2-3 weeks

Take your time - these fundamentals are critical for everything that follows!
