# Ethical Hacking Learning Path

A comprehensive repository of small projects to learn ethical hacking from scratch. This repository takes you from zero knowledge to understanding network vulnerabilities and exploitation techniques.

## 🎯 Learning Objectives

- Understand networking fundamentals and protocols deeply
- Learn low-level programming with C and Assembly
- Master network scanning and reconnaissance techniques
- Understand common vulnerabilities and how to exploit them responsibly
- Build tools from scratch to understand how they work

## 📚 Learning Path

This repository is organized into progressive levels:

### Level 0: Fundamentals
Basic building blocks - networking concepts and C programming
- **Project 0.1**: C Programming Basics & Memory Management
- **Project 0.2**: Networking Fundamentals & Socket Programming
- **Project 0.3**: Introduction to Assembly Language

### Level 1: Network Protocols
Understanding the TCP/IP stack by implementing it
- **Project 1.1**: Raw Sockets & Packet Crafting
- **Project 1.2**: TCP/IP Protocol Implementation
- **Project 1.3**: DNS Protocol & Queries

### Level 2: Network Scanning & Reconnaissance
Building your own network analysis tools
- **Project 2.1**: Port Scanner (TCP & SYN scan)
- **Project 2.2**: Network Packet Sniffer
- **Project 2.3**: ARP Scanner & Network Discovery

### Level 3: Vulnerability Analysis
Understanding common security vulnerabilities
- **Project 3.1**: Buffer Overflow Basics
- **Project 3.2**: Format String Vulnerabilities
- **Project 3.3**: Return-Oriented Programming (ROP)

### Level 4: Exploitation Techniques
Learning how exploits work
- **Project 4.1**: Shellcode Development
- **Project 4.2**: Writing Basic Exploits
- **Project 4.3**: Bypass Techniques (ASLR, DEP)
- **Project 4.4**: Malware Analysis & Creation (Educational)

### Level 5: Advanced Topics
Specialized security topics
- **Project 5.1**: Wireless Network Analysis
- **Project 5.2**: Cryptography & Hash Cracking
- **Project 5.3**: Web Application Security Basics

## 🛠️ Prerequisites

- Linux environment (Ubuntu/Debian recommended) or WSL on Windows
- GCC compiler for C programming
- NASM or similar assembler for Assembly
- Python 3.x (for some support scripts)
- Root/sudo access for some network-related projects

## 🚀 Getting Started

1. Clone this repository:
```bash
git clone https://github.com/alektebel/ethical-hacking.git
cd ethical-hacking
```

2. Start with Level 0 and progress sequentially
3. Each project has its own README with:
   - Concepts covered
   - Learning objectives
   - Implementation guide
   - Exercises and challenges
