# Level 2: Network Scanning & Reconnaissance

Learn to build network scanning and reconnaissance tools from scratch. These are essential skills for penetration testing and network security.

## Why Build Scanners?

Understanding how scanners work helps you:
- Perform network reconnaissance
- Identify live hosts and open ports
- Understand how attackers discover targets
- Build custom scanning tools for specific needs

## Projects in This Level

### Project 2.1: Port Scanner
Build a multi-threaded port scanner with various scanning techniques.

**Topics Covered:**
- TCP connect scan
- SYN scan (stealth scanning)
- Service detection
- Multi-threading for speed

### Project 2.2: Network Packet Sniffer
Create a packet sniffer to capture and analyze network traffic.

**Topics Covered:**
- Promiscuous mode
- Packet capture
- Protocol parsing
- Traffic analysis

### Project 2.3: ARP Scanner
Implement an ARP-based network discovery tool.

**Topics Covered:**
- ARP protocol
- Network discovery
- MAC address resolution
- Local network mapping

## Prerequisites

- Completed Level 0 and Level 1
- Understanding of TCP/IP
- Raw socket programming
- Threading concepts

## Legal and Ethical Considerations

⚠️ **CRITICAL**: Port scanning can be illegal when performed without authorization.

**Guidelines:**
- Only scan networks you own
- Get written permission before scanning corporate networks
- Some countries have strict laws about network scanning
- Unauthorized scanning can result in criminal charges

**Ethical Use:**
- Security audits (with permission)
- Network administration
- Penetration testing (contracted)
- Personal learning on your own networks

## Tools You'll Need

- Wireshark (for comparison and analysis)
- nmap (to compare your results)
- Virtual machines (for safe testing)
- Isolated network (recommended)
